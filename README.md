# grok_hackathon_frontend

Frontend and pitch of the Grok fleet command platform.

- `app/` - the web UI (Vite + React): chat, live video per device, device status, mission timeline, confirm dialog, STOP.
- `slides/` - the pitch deck.

It is a submodule of [`eddii1/grok_hackathon`](https://github.com/eddii1/grok_hackathon). The UI talks to the backend through the `/ws` event contract in [`docs/plan.md`](https://github.com/eddii1/grok_hackathon/blob/main/docs/plan.md).

**Tasks:** in the backend repo's [`TASKS.md`](https://github.com/eddii1/grok_hackathon_backend/blob/main/TASKS.md) (sections F and K).
